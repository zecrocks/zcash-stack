{{- if and .Values.grpcweb.enabled .Values.grpcweb.ingress.enabled .Values.grpcweb.ingress.hosts }}
{{- $host := index .Values.grpcweb.ingress.hosts 0 }}
{{- $paths := .Values.grpcweb.routes | default (list (dict "path" .Values.grpcweb.path)) }}

gRPC-web proxy is reachable at:
{{- range $r := $paths }}
  - https://{{ $host }}{{ $r.path }}
{{- end }}
Smoke test (GetLightdInfo over grpc-web). The frame must come from a file: a
$'\x00...' shell argument is truncated at the first NUL and the body goes out empty.
  printf '\x00\x00\x00\x00\x00' > /tmp/f
  curl -s -X POST https://{{ $host }}{{ (index $paths 0).path }}/cash.z.wallet.sdk.rpc.CompactTxStreamer/GetLightdInfo \
    -H 'content-type: application/grpc-web+proto' -H 'x-grpc-web: 1' --data-binary @/tmp/f | head -c 200
NOTE: opening these URLs in a browser returns 415. grpc-web requires a POST with that
content-type, which the address bar cannot send.
{{- end }}
